Algoritmo Merge(A, B, n, m)

    i ← 0
    j ← 0
    k ← 0

    C ← Arreglo de tamaño n + m

    Mientras i < n Y j < m Hacer

        Si A[i] < B[j] Entonces
            C[k] ← A[i]
            i ← i + 1
        SiNo
            C[k] ← B[j]
            j ← j + 1
        FinSi

        k ← k + 1
    FinMientras

    Mientras i < n Hacer
        C[k] ← A[i]
        i ← i + 1
        k ← k + 1
    FinMientras

    Mientras j < m Hacer
        C[k] ← B[j]
        j ← j + 1
        k ← k + 1
    FinMientras

    Retornar C

FinAlgoritmo
